# Saatci

Kadikoy'den Mektuplar / Letters from Kadikoy.

A series of letters written as self-contained interactive pages, in Turkish and English. Each letter is a single HTML file with no external dependencies.

## Structure

```
index.html          cover page, lists all letters in both languages
tr/mektup-N.html    Turkish letters, numbered
en/letter-N.html    English letters, numbered
```

## Letters

| N | Turkish                           | English                       |
| - | --------------------------------- | ----------------------------- |
| 1 | Mucize Kalemdi                    | The Pencil Was the Miracle    |
| 2 | Rus İmparatorluğu'na Hoş Geldiniz | Welcome to the Russian Empire |

## Serving

Served via GitHub Pages from the repository root. Every page is standalone: open any file locally in a browser and it works.
